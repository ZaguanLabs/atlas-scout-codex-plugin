# Security Policy

Report suspected vulnerabilities privately to <support@atlasscout.dev>. Include the plugin and
Bit Lantern versions, operating system, impact, a minimal reproduction, and any known workaround.
Do not open a public issue before a coordinated fix is available.

Zaguán Labs aims to acknowledge reports within three business days, assess severity, and coordinate
disclosure and a signed patched release. Never include private source code, credentials, license
tokens, or customer data unless an encrypted transfer method has been agreed in advance.

Bit Lantern indexes untrusted source text but does not execute repository code, hooks, package
scripts, builds, or tests. Release artifacts provide SHA-256 checksums, OpenPGP signatures,
Sigstore provenance, and SPDX SBOMs. Installation and verification guidance is published at
<https://atlasscout.dev/docs>.
